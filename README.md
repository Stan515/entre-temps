# ENTRE-TEMPS

Prototype MVP en HTML, CSS et JavaScript vanilla.

## Lancer le projet

Ouvrez simplement `index.html` dans un navigateur. Aucune installation n'est nécessaire.

## Parcours inclus

- Choix du temps disponible
- Choix de l'expérience
- Choix d'un sujet
- Mission interactive à choix multiples
- Explications et progression
- Écran de fin
- Passeport de connaissances sauvegardé dans le navigateur

Le projet est prêt à être publié avec GitHub Pages : dans le dépôt GitHub, ouvrez **Settings → Pages**, choisissez **Deploy from a branch**, puis la branche `main` et le dossier `/ (root)`.
